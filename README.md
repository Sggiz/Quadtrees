# Applications of the Quadtree data structure

Quadtree is a data structure useful for representing objects (mainly points) in a bidimensional space.

The first application of this here is a simulated solution to the astrophysical n-body problem, using the quadtree structure to simplify calculations of gravitational interactions. Ideas for this application come from : https://people.eecs.berkeley.edu/~demmel/cs267/lecture26/lecture26.html
